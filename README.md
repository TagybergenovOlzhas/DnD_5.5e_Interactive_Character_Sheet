# Интерактивный Лист Персонажа D&D 5.5e (2024)

Веб-приложение для ведения интерактивных листов персонажей **D&D 5.5e (редакция 2024 года)** с автоматической загрузкой справочника заклинаний из закрытого репозитория кампании.

Никаких дополнительных настроек или `.env` файлов создавать **не нужно** — доступ к справочнику заклинаний уже встроен. При каждом включении приложение автоматически скачивает и обновляет базу заклинаний.

---

## Как запустить приложение на любом компьютере (через Docker)

### Шаг 1. Установите Docker Desktop
Если у вас ещё не установлен Docker:
1. Скачайте и установите **[Docker Desktop](https://www.docker.com/products/docker-desktop/)**.
2. Запустите программу **Docker Desktop** и дождитесь, пока она включится (индикатор внизу слева станет зелёным).

---

### Шаг 2. Включите приложение

#### Вариант А — В один клик (Windows)
Просто дважды кликните по файлу **`start.bat`** в папке проекта.
Скрипт сам соберёт и запустит приложение, после чего автоматически откроет его в вашем браузере!
*(Чтобы выключить приложение, дважды кликните по файлу `stop.bat`).*

#### Вариант Б — Через терминал (Windows / macOS / Linux)
Откройте терминал в папке проекта и выполните одну команду:

```bash
docker compose up -d --build
```

После запуска откройте в браузере:
👉 **http://localhost:3000**

Остановить приложение можно командой:
```bash
docker compose down
```

---

## Где хранятся созданные персонажи?

Все созданные персонажи и скачанный справочник автоматически сохраняются в папке **`data/`** внутри проекта (`data/dnd.sqlite`):
- При обновлении страницы, перезапуске контейнера или перезагрузке компьютера **все ваши персонажи остаются на месте**.
- Чтобы перенести своих персонажей на другой компьютер или сделать резервную копию, достаточно скопировать файл `data/dnd.sqlite`.

## Запуск без Docker (для разработчиков через Node.js)

Если вы хотите запустить проект напрямую через Node.js (v20+ и установленный Git):

```bash
npm install
npm run dev
```
В режиме разработки клиент открывается по адресу **http://localhost:5173**.
